# ADR 0005: Append-only observations plus current projections

- Status: accepted
- Date: 2026-11-20
- Blueprint reference: section 22 (initial ADR set), ADR-005

## Context
Baseline decision recorded from the system design blueprint (MARKETPULSE_AI_SYSTEM_DESIGN.md, section 22). The blueprint's stated reason: Preserve source history and support reproducible analytics.

## Decision
Append-only observations plus current projections.

## Alternatives considered
See the blueprint section that this decision supports. Alternatives are expanded here if and when the decision is challenged during implementation.

## Consequences
Preserve source history and support reproducible analytics. Any change to this decision requires a new ADR that supersedes this one.

## Verification
