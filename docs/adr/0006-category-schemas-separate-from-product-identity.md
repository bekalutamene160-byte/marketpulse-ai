# ADR 0006: Category schemas/configuration separate from universal product identity

- Status: accepted
- Date: 2026-11-20
- Blueprint reference: section 22 (initial ADR set), ADR-006

## Context
Baseline decision recorded from the system design blueprint (MARKETPULSE_AI_SYSTEM_DESIGN.md, section 22). The blueprint's stated reason: Add ordinary product categories without hardcoding domain logic.

## Decision
Category schemas/configuration separate from universal product identity.

## Alternatives considered
See the blueprint section that this decision supports. Alternatives are expanded here if and when the decision is challenged during implementation.

## Consequences
Add ordinary product categories without hardcoding domain logic. Any change to this decision requires a new ADR that supersedes this one.

## Verification
First exercised in: Phase 3. The exit gate of that phase in blueprint section 20 is the acceptance check.
