# ADR 0011: Source connectors normalize into common contracts and preserve provenance

- Status: accepted
- Date: 2026-11-20
- Blueprint reference: section 22 (initial ADR set), ADR-011

## Context
Baseline decision recorded from the system design blueprint (MARKETPULSE_AI_SYSTEM_DESIGN.md, section 22). The blueprint's stated reason: Website/platform independence and consistent downstream behavior.

## Decision
Source connectors normalize into common contracts and preserve provenance.

## Alternatives considered
See the blueprint section that this decision supports. Alternatives are expanded here if and when the decision is challenged during implementation.

## Consequences
Website/platform independence and consistent downstream behavior. Any change to this decision requires a new ADR that supersedes this one.
